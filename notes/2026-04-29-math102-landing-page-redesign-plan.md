> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

- [ ] **Step 4: Write the grading policy block with the formula and example**

The landing page must include:

```text
Exam I: 70/300 (23.33%)
Exam II: 70/300 (23.33%)
Final Exam: 100/300 (33.34%)
Lab Python: 30/300 (10%)
Class Work: 30/300 (10%)
```

and the classwork rule:

```text
y = 3 * (median(Exam I %) + median(Exam II %)) / 20
```

with the interval:

```text
[y - 1, y + 1]
```

and the worked example:

```text
If the Exam I median is 72% and the Exam II median is 68%, then
y = 3 * (72 + 68) / 20 = 21,
so the section classwork average should lie in [20, 22].
```
